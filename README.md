
BMI Calculator
 Project Overview

The BMI Calculator is a simple Python application that calculates a person's Body Mass Index (BMI) using their weight and height. It helps users understand their weight category based on their BMI value.

 Objectives
Calculate BMI based on weight and height.
Classify BMI into standard adult weight categories.
Practice Python programming, user input, mathematical calculations, and conditional statements.
 Technologies Used
Programming Language: Python
Concepts: Variables, user input, arithmetic operations, and conditional statements.
 BMI Formula

BMI is calculated using the following formula:

BMI = Weight (kg) / Height (m)²

For example, if a person's weight is 65 kg and their height is 1.70 m:

BMI = 65 / (1.70 × 1.70) = 22.49

 BMI Categories for Adults
BMI Range	Category
Below 18.5	Underweight
18.5–24.9	Healthy weight
25.0–29.9	Overweight
30.0 and above	Obesity

These are general adult screening categories, not a diagnosis.

 How to Run the Project
Install Python on your computer.
Download or clone this repository.
Open the project folder in VS Code.
Open the terminal.
Run the Python file:
bash
python bmi_calculator.py


Replace bmi_calculator.py with your actual Python filename if it is different.

Enter your weight in kilograms and height in meters when prompted.
View your calculated BMI and category.

text

Example output assumes the program uses the formula and adult categories described above.

 Limitations
BMI is a general screening tool and does not directly measure body fat.
Adult categories are not appropriate for children and teenagers, who require age- and sex-specific interpretation.
BMI alone cannot determine a person's overall health.
