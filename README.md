BMI Calculator
Project Overview

The BMI Calculator is a simple Python application that calculates a person's Body Mass Index using their weight and height. It helps users understand their weight category based on their BMI value.

Objectives
Calculate BMI using weight and height.
Classify BMI into standard adult weight categories.
Practice Python programming, user input, mathematical calculations, and conditional statements.

Programming Language: Python
Variables and data types

BMI Formula

BMI is calculated using the following formula:

BMI = Weight in kilograms / Height in meters squared

For example, if a person's weight is 65 kilograms and their height is 1.70 meters:

BMI = 65 / (1.70 * 1.70)

BMI = 22.49

BMI Categories for Adults
BMI Range	Category
Below 18.5	Underweight
18.5 to 24.9	Healthy weight
25.0 to 29.9	Overweight
30.0 and above	Obesity

These categories are general screening guidelines for adults and are not a medical diagnosis.

How to Run the Project
Install Python on your computer.
Open the project folder in Visual Studio Code.
Open the terminal.
Run the Python program using the following command:

python bmi_calculator.py

Enter your weight in kilograms when prompted.
Enter your height in meters when prompted.
