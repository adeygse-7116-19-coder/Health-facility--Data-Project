
# BMI Calculator

## Project Overview

The BMI Calculator is a simple Python program that calculates a person's Body Mass Index (BMI) based on their weight and height. It helps users identify their weight category using standard adult BMI ranges.

## Objectives

- Calculate BMI using weight and height.
- Identify BMI categories for adults.
- Practice basic Python programming.
- Understand user input, mathematical operations, and conditional statements.

## Technologies Used

- Python
- Visual Studio Code

## BMI Formula

BMI is calculated using the following formula:

BMI = Weight (kg) / Height (m)²

Example:

Weight = 65 kg

Height = 1.70 m

BMI = 65 / (1.70 × 1.70) = 22.49

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5–24.9 | Healthy weight |
| 25.0–29.9 | Overweight |
| 30.0 and above | Obesity |

These ranges are general screening guidelines for adults and are not a medical diagnosis.

## How to Run the Project

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the Python program:

   ```bash
   python bmi_calculator.py
   ```

5. Enter your weight in kilograms.
6. Enter your height in meters.
7. View your BMI result and category.

Note: Replace `bmi_calculator.py` with the actual name of your Python file if it is different.

## Example Output

```text
Enter your weight in kg: 65
Enter your height in meters: 1.70

Your BMI is: 22.49
Category: Healthy weight
```

## Limitations

- BMI does not directly measure body fat.
- Adult BMI categories are not intended for children and teenagers.
- BMI alone cannot determine a person's overall health.
